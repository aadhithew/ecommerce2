FORM & FIELD — MULTIPAGE DEMO STORE

Open index.html to browse, or serve this directory with any static web server. Each page lives in its own folder with an index.html file. Shared styles and scripts live under assets/.

Product images and fonts require an internet connection. For consistent cart storage between pages, use a local web server rather than file://.

Checkout, account forms, newsletter, and contact form are demonstrations. No payment or message is sent. Cart and last demo order are stored in the browser.
